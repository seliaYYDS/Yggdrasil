# clock

最小的"给界面加一个页面"的例子：一个走着的时钟，外加一个"记下此刻"按钮。

它只用 React 自己的状态（`useState` + `setInterval`），不碰网络、不碰提示词、不派生 Agent ——
用来证明**插件页面是真的在跑的组件**（自己计时、自己重渲染、自己放按钮），而不是一段静态标记。

## 清单里就一段

    "pages": [
      { "id": "clock", "label": "时钟", "file": "ui/clock-page.tsx",
        "icon": ["M12 2a10 10 0 1 0 0 20 10 10 0 1 0 0-20", "M12 7v5l3 2"] }
    ]

`icon` 是**工具栏按钮的图标**：SVG path 的 `d`，一条或多条，坐标是 Lucide 那套 24×24。

只收 path 是有意的：它是纯数据，宿主可以直接检查（只允许路径命令与数字），
并且描边粗细、颜色、圆角都由宿主统一决定 —— 所以插件的图标与内置图标**观感一致**。
不写 `icon` 就退回通用图标。

## 两个插件的按钮会分开

装了 `clock` 与 `brief` 之后，工具栏上它们的按钮**各成一组**（组间多留一点间距），
每个按钮用各自清单里声明的图标。分组只是视觉：点击与层级行为完全一样。
