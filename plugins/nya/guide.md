# nya

最小的"**只改 Agent 行为、别的什么都不加**"的插件：往系统提示里插一段口吻要求，
让 Agent 说话像一只猫娘。没有端点、没有工具、没有按钮、不联网。

## 那段提示词

它插在 `output-format` **之前**（也就是输出契约的紧上边）。措辞分两层：

1. **怎么说**：自称「本喵」，句尾带「喵」「喵～」，语气亲昵活泼；
2. **说什么**：JSON 的字段名、`kind`、`ops` 形状、"只输出一个 JSON 对象"—— 一个字都不许变。

第二层不是客套话，是这类插件的**主要风险**：语气提示词最经典的翻车方式就是
模型一兴奋把结构忘了（换行拆开 JSON、加注释、加代码块，或者干脆用自然语言回答）。
所以这段文字把"怎么说"和"说什么"明确切开，并把结构要求再钉一遍。

写自己的口吻插件时照这个结构写就行。

## 为什么插在 output-format 之前

那里离输出契约最近，"别看语气看结构"这句话才有分量。插在很靠前的地方
（比如 `identity` 附近）离契约太远，模型容易在长长的提示词里把这条忘掉。

顺带说一句：因为补丁是**每轮拼提示词时现读**的，在插件面板里关掉它，
Agent 下一轮就立刻改回原来的语气，不用重启。

## 试一下

装上后跟 Agent 说随便什么（比如"帮我做个时钟组件"），看它的 `reasoning`
以及它写给你的话是不是变成了猫娘口吻 —— 同时确认 **JSON 还是好好的**：
组件照常建出来，说明结构没被语气带跑。
