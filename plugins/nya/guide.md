# nya

最小的"**只改 Agent 行为、别的什么都不加**"的插件：把 Agent 的名字从 `Yggdrasil` 改成「小喵」，
并往系统提示里插一段口吻要求，让它说话像一只猫娘。没有端点、没有工具、没有按钮、不联网。

## 两条补丁

    "prompts": [
      { "op": "substitute", "find": "Yggdrasil", "replace": "小喵", "label": "改名" },
      { "op": "insert", "anchor": "output-format", "position": "before",
        "label": "猫娘口吻", "text": "…" }
    ]

**为什么改名要用 `substitute` 而不是 `replace`**：名字出现在 `identity` 那一段里，
而 `identity` 是**受保护段落**（不允许 replace / remove —— 删了 Agent 就不知道自己是谁、
能调什么）。所以"把提示词里的某个名字统一改掉"用前三种 op 一个也做不到：
要改的是受保护段落里的**几个词**，不是整段。

`substitute` 就是为这种情况加的：**逐字替换整份提示词**。
它有意用字面量而不是正则 —— 声明要能被静态读懂（"把 Yggdrasil 换成小喵"），
正则既难审，也容易写出灾难性的回溯。

⚠ 它也是这条能力里**最强**的一个 op：作用在整份提示词上，**连输出契约都能改到**。
所以安装确认里单独列出来、并写明"会改写全篇"。写自己的插件时别拿它去动结构性的词。

## 那段口吻提示词

分两层：

1. **怎么说**：自称「本喵」，句尾带「喵」「喵～」，语气亲昵活泼；
2. **说什么**：JSON 的字段名、`kind`、`ops` 形状、"只输出一个 JSON 对象"—— 一个字都不许变。

第二层不是客套话，是这类插件的**主要风险**：语气提示词最经典的翻车方式就是
模型一兴奋把结构忘了（换行拆开 JSON、加注释、加代码块，或者干脆用自然语言回答）。
所以那段文字把"怎么说"和"说什么"明确切开，并把结构要求再钉一遍。

插在 `output-format` **之前**：那里离输出契约最近，这句提醒才有分量。

### 写这段文字时踩到的坑

**不要在自己插入的文字里写出旧名字。**

`substitute` 跑在**最后**、作用在整份提示词上 —— 它会连你这句解释里的
旧名字一起换掉。第一版我写的是"凡是提到「Yggdrasil」的地方指的都是你"，
换完之后变成"凡是提到「小喵」的地方指的都是你"，自相矛盾。

所以这段文字里既不写旧名字，也不写新名字，改成中性的说法
（"你叫什么以提示词开头那句身份说明为准"）。这样它对**子 Agent** 也成立 ——
它们是独立个体、名字不是小喵，身份以各自那句为准。

## 试一下

装上后跟 Agent 说随便什么（比如"帮我做个时钟组件"），看它的 `reasoning`
以及它写给你的话是不是变成了猫娘口吻、有没有自称「小喵」——
同时确认 **JSON 还是好好的**：组件照常建出来，说明结构没被语气带跑。

## 关掉 / 卸载

补丁是**每轮拼提示词时现读**的，所以在插件面板里关掉它，Agent 下一轮就立刻改回
原来的名字与语气，不用重启；卸载则完全回到装之前。
